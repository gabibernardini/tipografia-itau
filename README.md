# tipografia-itau

# 📌 Sobre o projeto

Este trabalho apresenta uma proposta de identidade visual para o Itaú, desenvolvida no Figma. O objetivo é organizar os principais elementos visuais da marca e demonstrar como eles podem ser aplicados de forma padronizada.

# 🎯 Objetivo do projeto

O objetivo é definir e organizar elementos de tipografia, cores, escala de fontes e contraste, criando uma referência visual para manter a identidade da marca consistente em diferentes aplicações.

# 🎨 Elementos apresentados

O projeto contém:
- Logo da marca;
- Paleta de cores, com tons de laranja, azul, verde, vermelho, preto e branco;
- Tipografia Poppins, apresentada em diferentes pesos;
- Escala tipográfica, com tamanhos de 14px a 40px;
- Exemplos de contraste entre textos e fundos.

# 🛠️ Ferramenta utilizada

O projeto foi desenvolvido utilizando o Figma.
